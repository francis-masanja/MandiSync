# MandiSync Documentation

Welcome to the **MandiSync** project documentation. This repository implements an IoT-enabled APMC gateway for agricultural supply chain management, featuring:

- Farmer portal for booking deliveries
- RFID gate control desk
- Weighbridge integration with LittleFS storage
- Live queue ledger
- ESP32 firmware viewer

The docs folder contains architecture overviews, API specifications, component references, and data model definitions.
