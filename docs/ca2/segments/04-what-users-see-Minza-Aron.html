Segment 4

What Users See

We used soft glass cards on the screens, paired with a green primary colour and a step-by-step booking flow. For the gate and weighbridge screens, the controls are large to handle a busy counter.

Minza Aron Frontend

In one minute

This part is about the screens themselves. It is not about the database or the servers. It is about what a farmer, a gate guard, or a weighbridge operator actually taps and reads.

The idea is simple: one clear next step, big controls, and status you can understand even if you are colour-blind or standing in bright sunlight.

What this part covers

Using the farmer portal feels like a wizard: you pick a mandi, then select the crop and its weight, set a time window, and press confirm. At the gate desk you see the scanned tag, the booking and whether it's open or denied. The weighbridge screen displays the current weight along with the gross and tare actions. Meanwhile, the queue ledger lists the live list and shows the daily counts.

The design sticks with emerald for primary actions and success, amber when something's waiting or hitting a capacity limit, red for any errors, and slate for regular text. We always show the status both as text and in colour. Because the layout is responsive, the main controls are big enough to work comfortably on a phone or a counter tablet.

Key terms

Glassy-clayA visual style with translucent cards, soft shadows and rounded corners.
WizardA form split into steps so the user only sees one decision at a time.
ResponsiveA layout that adapts to phone, tablet and desktop widths.
ContrastThe difference between text and background; higher contrast is easier to read.

Farmer booking

Gate desk

Weighbridge & queue

The operator sees the current weight with gross and tare actions, alongside the live queue and daily counts.

What to remember

  • One step at a time: the booking flow only shows the next decision.
  • Big controls on the gate and weighbridge screens, because the counter is busy.
  • Status is shown as text plus colour, so colour is never the only clue.
  • The layout is responsive, so it works on a phone or a counter tablet.
